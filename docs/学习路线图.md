# lania-g v3 学习路线图

## 1. 目标

本文档给出一条适用于当前多 module 版本的学习路线。示例中的 import 统一使用真实 module path `github.com/sao-lang/lania-g/...`。

你最终需要达到的状态：

- 会用：能装配一个最小服务，跑通协议路由与参数绑定。
- 会接入：能按需引入 logger、config、orm、otel 等 integrations。
- 会扩展：能理解从声明到编译安装再到运行期执行的主链路。
- 会维护：知道哪些包是稳定依赖面，哪些只该在框架内部使用。

## 2. 第 0 天：先搞清依赖边界

优先记住业务侧稳定依赖面：

- `github.com/sao-lang/lania-g/application/v3`
- `github.com/sao-lang/lania-g/kernel/v3/module`
- `github.com/sao-lang/lania-g/kernel/v3/di`
- `github.com/sao-lang/lania-g/protocol/<proto>/v3`
- `github.com/sao-lang/lania-g/protocol/<proto>/v3/binding`
- `github.com/sao-lang/lania-g/integrations/<name>/v3`

框架维护时再深入：

- `github.com/sao-lang/lania-g/kernel/v3/registry`
- `github.com/sao-lang/lania-g/kernel/v3/compiler`
- `github.com/sao-lang/lania-g/kernel/v3/runtime`
- `github.com/sao-lang/lania-g/kernel/v3/graph`

## 3. 第 1-2 天：跑通一个最小 HTTP 服务

推荐阅读：

1. [README.md](../README.md)
2. [标准接入模板.md](标准接入模板.md)
3. [API.md](API.md)

建议练习：

1. 按标准模板抄一份最小服务。
2. 把路由改成 `/ping`。
3. 启动前显式执行 `CompileDiagnostics()` 与 `StartupReport()`。

自检方式建议在你改动的模块目录执行，例如：

```bash
cd protocol/http/v3
go test ./...
```

## 4. 第 3-4 天：理解主线链路

牢记这条主线：

```text
Module
  -> Application
  -> Protocol Module 挂载
  -> Compile / Install
  -> Listen / Run
```

建议对照阅读：

1. [application.go](../application/v3/application.go)
2. [compile.go](../kernel/v3/compiler/compile.go)
3. [context.go](../kernel/v3/runtime/context.go)
4. [plugin.go](../protocol/http/v3/plugin.go)

## 5. 第 5-7 天：接入一个真实 integration

任选一个你最常用的 integration：

- logger
- config
- orm
- otel
- swagger
- terminus

练习目标：

- 用 `ForRoot(...)` 接入模块
- 在 handler 或 service 中取到注入对象
- 明确它是否还需要额外 `Install(app, ...)` 或 bridge
